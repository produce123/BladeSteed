# 刀马 · BladeSteed

一个 **2–4 人联机武侠猜拳小游戏**。纯前端、零依赖、零构建，直接丢到 GitHub Pages 就能玩 —— 没有服务器，没有数据库，没有账号。

> 一座座城里的人各自为战。猜拳赢的人才能动手：买刀、买马、出城、进城、砍一刀、踹一脚。
> 十点血，出城容易进城难，最后站着的人赢。

---

## 在线试玩

部署后地址形如 `https://<用户名>.github.io/BladeSteed/`。

- **人机对局**：单机，2/3/4 人，AI 会记仇、会算局势，但**它分不出谁是真人谁是 AI**
- **在线对局**：房主建房拿到 6 位房间号，其他人在同一页输入房间号即可加入
- **游戏规则**：页内完整规则说明

## 规则（唯一版本，代码严格按此实现）

### 人数与胜负
- 支持 **2 / 3 / 4 人**，开局随机分配座位号。
- 每人 **固定 10 点血**，血量 ≤ 0 立刻出局。
- 最后活着的人获胜，结束后可**一键重新开局**。

### 位置
- 世界上只有两种位置：**某人的城里** 和 **野外**。
- 开局时每个人都在**自己的城**里。
- 城是**永久**的：就算城主出局了，他的城依然可以被别人进入。

### 装备
- 装备**永久有效**，只能在**城里**买（任何人的城都行，包括自己的和已出局者的）。
- 买刀 → 解锁【刀】：**1 点伤害**，城里、野外都能用。
- 买马 → 解锁【踹】：**3 点伤害**，但要求双方**在同一座城里**，踹完把对方**踢到野外**。
- 买东西**不花钱**，但**要花一步行动**。

### 每回合流程
1. **全体同时猜拳**（自己选，系统统计）。
2. 结算：
   - **恰好 1 个赢家** → 他获得 **2 步**行动。
   - **多个赢家** → 每人 **1 步**，然后赢家之间再猜拳，
     反复淘汰直到剩下**唯一一人**，由他来**指定所有赢家的行动顺序**。
   - **没有赢家**（三平局 / 各出一手）→ **重新猜拳**。
3. **1 步 = 1 个操作**；2 步 = 任意两个操作的组合。

### 可用操作
| 操作 | 前置条件 |
|---|---|
| 买刀 | 自己在城里，且还没买过 |
| 买马 | 自己在城里，且还没买过 |
| 出城 | 自己在城里（无其它前置，任何回合都能走） |
| 进城 | 选一座城（自己的、别人的、出局者的都行） |
| 刀 | 有刀，且双方**在同一位置**（同城或同在野外） |
| 踹 | 有马，且双方**在同一座城里** |
| 结束行动 | 随时，放弃剩余步数 |

> 也支持**中途加入**：对局进行中进来的人从下一个猜拳回合开始参与；
> 断线的人由房主判定为**自动出局**。

## 技术实现

### 零依赖、零构建
全部是浏览器原生 ES Module，没有打包器、没有 npm 依赖。
本地起个静态服务器就能跑（`file://` 下 ES Module 会被浏览器拦，所以要用服务器）：

```bash
node tools/serve.mjs 8080     # 然后打开 http://127.0.0.1:8080
```

### 联机：没有后端的 P2P
```
        公共信令通道（MQTT over WSS / ntfy.sh）
                     │  只用来找人和兜底中转
                     ▼
   客户 A ◄──── WebRTC DataChannel ────►  房主  ◄──── 客户 B
                                          ▲
                                    唯一的权威状态机
```
- **配对靠公共通道撮合**：`客人广播 HELLO → 房主回 HOST_PRESENT → 交换 SDP → 建立 DataChannel`。
  房间号就是频道名，不需要任何自建服务。
- **中转兜底**：对称 NAT / 防火墙 / 同局域网握手失败时，链路自动标记为 `relay`，
  对局消息改由公共通道转发。星型拓扑下每个客户端只跟房主通信，中转量很小。
- **房主是唯一权威**：客户端只发「操作意图」，所有规则校验、状态裁剪、广播都在房主那边。
  客户端拿到的永远是 `viewFor(自己)` 裁剪过的那一份 —— **别人还没揭晓的拳，物理上到不了你手上**。
- **抗丢包**：公共通道是 QoS0，会丢消息。所以：
  - 操作带 `actionId`，没收到回执就重发，房主按 id 去重；
  - 状态帧是**完整快照**并带 `rev`，幂等覆盖，丢一帧不会让人卡在旧状态；
  - 房主每 2 秒给所有人补发一次全量状态。
- **心跳**：3 秒一次 PING/PONG，15 秒听不到房主的声音就提示掉线；房主 15 秒收不到某个客人的消息就判他出局。

### AI
- AI 拿到的**和人类客户端完全一样的视图**（`viewFor` 的产物）。
  视图里**从不包含 `isAI`** —— 这不是「AI 不看」，而是**结构上拿不到**，所以它不可能针对真人或放过真人。
- AI 有稳定的性格（由玩家 id 哈希决定），会记仇、会统计对手出拳习惯，但**局势优先于情绪**。
- `js/engine/rules.js` 里的 `legalActionsFrom()` 是**合法操作的唯一来源**：
  引擎校验、界面按钮、AI 决策空间全都从这里取，三边不可能对不上。

### 界面
- 纯 **SVG** 战场：头像就是 DOM 元素，点得到、有热区、位置变化靠 CSS `transform` 补间，
  动画不占主线程，也不用自己做坐标换算。
- 特效全部是「一次性」的：飞一个元素、爆几颗粒子，动画一结束立刻从 DOM 摘掉，没有 rAF 轮询。
- 深色护眼配色，底部操作区为拇指设计，按钮 ≥ 48px。
- 尊重 `prefers-reduced-motion`，也提供手动「音效 / 特效」开关。

## 测试

四层测试，全部零依赖，全部可以单独跑：

```bash
node tests/rules.test.mjs     # 规则单测：合法操作、结算、超时、视图不泄露
node tests/sim.mjs 4000       # AI 自对弈压力测试：4000 局，查死锁 / 非法操作 / 座位胜率
node tests/net.test.mjs       # 联机集成：真去连公共通道，三人配对 + 打完一局 + 断线判负
node tests/e2e.test.mjs       # 浏览器端到端：真实无头 Chrome，真人点头像打完整局
```

或一次跑完：`node --run test:all`（或 `npm run test:all`）。

`tests/e2e.test.mjs` 会用真实的无头 Chrome/Edge：
- 用**真实鼠标点击**按钮打完 4 人机局，再点「一键重新开局」验证状态复位；
- 验证扔鸡蛋 / 鲜花、菜单、规则页、单字名校验；
- 开 **3 个浏览器**靠房间号配对，自动打完一局，比对三家看到的公开状态是否**完全一致**；
- 在 **360×640 / 390×844 / 820×1180 / 1440×900** 四种视口下检查横向纵向都不溢出、
  按钮不小于 48px、头像不跑出画布，并把截图存到 `tests/screenshots/`；
- 任何控制台报错或未捕获异常都算失败。

`tests/sim.mjs` 用假时钟瞬间跑完整局，检查：
血量范围、存活与血量一致、位置合法、只有活人进队列、当前行动者活着、
**任何局面下至少有一个合法操作**（不会死锁）、胜者自洽、各座位胜率偏差不超过阈值。

## 部署到 GitHub Pages

1. 推到仓库 `main` 分支。
2. 仓库 **Settings → Pages → Source: Deploy from a branch → main / (root)**。
3. 等一分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

仓库里已经放好了 `.nojekyll`（避免 Jekyll 处理静态资源）。全站都是相对路径，放在子目录下也能正常工作。

## 目录

```
index.html            六个屏幕：首页 / 人机 / 在线 / 大厅 / 牌桌 / 规则
css/style.css         深色主题、布局、SVG 地图样式、特效关键帧
js/
  main.js             入口
  engine/
    constants.js      血量、伤害、阶段、操作类型、超时
    rng.js            可复现的种子随机数
    rules.js          legalActionsFrom —— 合法操作的唯一来源
    engine.js         Match：状态机（猜拳结算、最小猜拳、行动、伤害、出局）
    view.js           viewFor：按人裁剪视图（唯一秘密是未揭晓的拳）
  ai/ai.js            AiBrain：性格、记仇、出拳统计、行动打分
  game/
    emitter.js        极简事件发射器
    match.js          GameDriver：引擎 + AI + 超时心跳
  net/
    protocol.js       消息类型、房间号、信封
    mqtt.js           MQTT over WSS 信令通道
    channels.js       SignalBus：多通道竞速 + ntfy 兜底
    rtc.js            PeerLink：DataChannel 直连，失败自动转中转
    session.js        LocalSession / HostSession / ClientSession
  ui/
    map.js            SVG 战场渲染
    effects.js        飞行道具、爆开、刀光、飘字、播报
    audio.js          WebAudio 现场合成音效（不加载任何音频文件）
    app.js            屏幕切换、大厅、行动面板、事件回放
tools/
  serve.mjs           零依赖静态服务器
  cdp.mjs             极简 Chrome DevTools Protocol 驱动（测试用）
tests/                四层测试
```
